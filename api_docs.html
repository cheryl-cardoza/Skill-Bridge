REST API Reference

All endpoints return JSON. Base URL: http://localhost:5000

No authentication required for local use.

POST /api/predict

Predict a student's math score and get a full explanation of what drove the prediction.

Request body (JSON)

FieldTypeValues
genderstringmale / femalerequired
race_ethnicitystringgroup A … group Erequired
parental_level_of_educationstringsome high school, high school, some college, associate's degree, bachelor's degree, master's degreerequired
lunchstringstandard / free/reducedrequired
test_preparation_coursestringnone / completedrequired
reading_scorenumber0 – 100required
writing_scorenumber0 – 100required
modelstringLinear Regression, Ridge Regression, Random Forest, Gradient Boostingoptional

Example request

{
  "gender": "female",
  "race_ethnicity": "group C",
  "parental_level_of_education": "bachelor's degree",
  "lunch": "standard",
  "test_preparation_course": "completed",
  "reading_score": 75,
  "writing_score": 80
}
