# Student Performance Indicator

## 📌 Project Overview

The **Student Performance Indicator** is a Machine Learning project that analyzes student-related factors and predicts academic performance. The project uses student demographic, social, and educational information to understand the factors that influence students' academic outcomes.

The project includes data preprocessing, exploratory data analysis, feature engineering, model training, evaluation, and prediction.

---

## 🎯 Objectives

- Analyze factors affecting student academic performance.
- Perform data cleaning and preprocessing.
- Explore relationships between student attributes and academic scores.
- Train Machine Learning models for performance prediction.
- Evaluate and compare model performance.
- Provide insights that can help understand student achievement.

---

## 📊 Dataset

The dataset contains information about students, including demographic, educational, and socio-economic attributes.

Example features include:

- Gender
- Race/Ethnicity
- Parental Level of Education
- Lunch
- Test Preparation Course
- Math Score
- Reading Score
- Writing Score

The dataset is used to analyze and predict student performance.

> **Note:** The dataset is not included in this repository if it exceeds GitHub's file-size limits. Please place the dataset in the appropriate `data/` folder before running the project.
